# Услуги в проекте

Полный стартовый список зафиксирован в `backend/migrations/004_restore_services.sql` и добавляется при `app:migrate` на development и production. Описания, состав работ, сроки, цены и порядок находятся в репозитории; внешняя БД для их восстановления не нужна.

| Услуга | Slug | Цена | Источник |
|---|---|---:|---|
| Magento 2 Setup from Scratch | `magento-2-setup-from-scratch` | $299 | SQL 20260430121117, состав обновлён 20260520 |
| Extension Installation | `install-magento-2-extension` | $60 | История `7953278:src/data/mock.ts`; SQL 20260503 снижает цену до $60 |
| Security Patch Installation | `security-patches-installation` | $60 | История `7953278`, состав и название из SQL 20260520 |
| Optimize Magento 2 Speed | `magento-2-speed-optimization` | $200 | История `7953278:src/data/mock.ts` |
| Performance Audit | `performance-audit` | $499 | SQL 20260430121117, состав обновлён 20260520 |
| Hyvä Theme Migration | `hyva-theme-migration` | $2499 | SQL 20260430121117 |
| Transfer an Existing Magento Store | `transfer-existing-store` | По запросу | Состав из SQL 20260520; исходная цена и срок отсутствуют |
| Magento & Server Updates | `magento-server-updates` | $210 за 7 часов, далее $30/час | SQL 20260520 |
| Magento 1 to Magento 2 Migration | `migration-m1-to-m2` | По запросу, минимум 10 часов | Описание/состав/минимум из SQL 20260520; исходная ставка отсутствует |
| Migration Consultation | `migration-consultation` | $50 за 30 минут | История `7953278:src/data/mock.ts` |

Для установки Magento найдено два старых значения: $300 в статическом каталоге и $299 в более позднем SQL-источнике. Используется $299; главная получает цену из текущей записи услуги, чтобы не показывать другую сумму.

Для переноса магазина и полной миграции M1→M2 точная цена не выдумана: `price=0` обозначает запрос оценки. На карточке и подробной странице доступна связь с темой выбранной услуги; backend не разрешает оформить такую услугу как бесплатный заказ. Для серверных обновлений явно показан минимальный бюджет, без обещания выполнить весь объём за фиксированную сумму.

Старые URL `/services/extension-installation` и `/services/install-security-patches` перенаправляются на канонические адреса. Старые checkout-параметры поддерживаются. Дубликатов услуг в общем списке нет.

Установка расширения уже добавлена миграцией 003; миграция 004 сохраняет существующую запись и устанавливает порядок. Если услуга с тем же slug уже есть, пользовательский текст и цена не перезаписываются. Для последующих изменений использовать JSON-импорт/SQL, описанные в `docs/content.md`, или новую миграцию. Применённые SQL-файлы изменять нельзя из-за проверки checksum.

Для обновлений сервера отсутствовал список отдельных работ; он составлен из существующего описания (проверка версий, план обновления, backup, обновление стека, проверка магазина). Неизвестные сроки помечены как согласуемые после оценки.
