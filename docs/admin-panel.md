# Админ-панель

Адрес: `/admin_panel`. Панель работает на Symfony + Twig без отдельного frontend-приложения. Вход закрыт паролем, формы защищены CSRF, попытки входа ограничены. Панель не индексируется и не кешируется.

## Создать администратора

После миграций:

```bash
# Development
docker compose exec backend php bin/console admin:user:create admin@example.com

# Production
bash scripts/prod.sh exec backend php bin/console admin:user:create admin@example.com
```

Команда запросит пароль и повторное подтверждение скрытым вводом. Минимум 8 символов; email нормализуется в нижний регистр. Пароль хранится как хеш Symfony PasswordHasher. Существующая учётная запись не перезаписывается. Публичной регистрации нет.

Для автоматизации доступен `--password-stdin` с `--no-interaction`: передавать пароль через stdin из защищённого источника, не аргументом командной строки. Не сохранять действующие пароли в Git.

## Вендоры и модули

1. Нажать «Добавить модуль», в том числе внутри выбранного вендора.
2. Вставить ссылку на оригинальную страницу товара. При необходимости указать свою affiliate-ссылку.
3. Нажать «Загрузить модуль по ссылке». Название, описания, обложка, галерея, README / User Guide, цена в USD, рейтинг, возможности и совместимость извлекаются со страницы, когда эти данные там доступны. Фотографии скачиваются в локальное хранилище.
4. Новая карточка автоматически публикуется. Вендор берётся из выбранного раздела либо определяется по домену сайта; неизвестный вендор создаётся автоматически. Категория определяется по категории товара и хлебным крошкам источника, затем по названию, адресу и краткому описанию модуля. Нужная категория создаётся автоматически, если её ещё нет в каталоге. При отсутствии совпадения используется Other Extensions.
5. Повторная загрузка той же оригинальной ссылки обновляет карточку без дубля, сохраняя её адрес, публикацию и счётчики. Пустая affiliate-ссылка при повторном импорте не стирает существующую.

Все поля для ручной корректировки остаются в свёрнутом разделе «Ручная корректировка (необязательно)». Заполнять их для импорта не требуется.

При изменении цены установки в модуле учитывать цену услуги `services`: сумму заказа определяет backend по услуге. Непосредственно цены услуг управляются через текущий импорт/SQL; эта лёгкая панель предназначена для вендоров и модулей.

## Upload

Импорт и Upload также автоматически формируют отдельные SEO title и description из метатегов оригинала и данных модуля. Они доступны в необязательном разделе SEO и не меняют название карточки. Подробнее — [SEO](seo.md). Для заполнения старых записей без повторного скачивания фото: `docker compose exec backend php bin/console app:seo:refresh`.

Кнопка у каждого добавленного модуля читает сохранённую оригинальную ссылку. Обновляются доступные название, описания, цена в USD, рейтинг (шкала нормализуется к 5), обложка, галерея, категория, возможности, совместимость и README / User Guide. Affiliate-ссылка, slug, вендор, публикация и счётчики сохраняются. Загрузка запускается вручную, после входа и с CSRF-токеном.

Поддерживаются JSON-LD / Open Graph, товарная разметка Magento, галереи Hyvä и Magento, HTML-слайдеры Mageworx (включая ленивую загрузку `data-src`), карусели PhotoSwipe Plumrocket, ссылки на руководства в HTML. Для Mageworx выбираются полноразмерные скриншоты; миниатюры используются, если полноразмерной галереи нет. Ссылки User Guide имеют приоритет над упоминаниями руководств в описаниях, ссылки из навигации и футера исключены. Импорт CCPA Amasty, Marketing & Sales Suite Mageworx и Social Login Pro Plumrocket проверяется по настоящим страницам. Список скриншотов Plumrocket читается как JSON без выполнения JavaScript; видео не импортируются. За один импорт скачивается до 25 изображений; отсутствующие в источнике поля не выдумываются. Если фото или руководство недоступны, панель показывает предупреждение. Если сайт блокирует запрос или не отдаёт название/описание, импорт завершается ошибкой без создания пустой карточки. Ссылки на внутренние сети блокируются `NoPrivateNetworkHttpClient`. Иностранная валюта автоматически не переводится в USD.

Для файлов с компьютера используются отдельные поля главного фото и скриншотов в форме модуля. Разрешены проверенные по содержимому JPG/PNG/WebP до 8 МБ на файл; SVG, HTML, PHP и архивы не принимаются. Имена генерируются сервером, расширения берутся из MIME. За один запрос — до 8 дополнительных скриншотов; общий размер запроса ограничен 40 МБ.

## Счётчики

- `/go/module/{slug}` увеличивает открытия карточки и перенаправляет на `/extension/{slug}`. Обложка и название модуля в каталоге используют обычные ссылки, без Next.js prefetch.
- `/go/affiliate/{slug}` увеличивает партнёрские переходы и перенаправляет на сохранённую affiliate-ссылку; если она пуста — на оригинал.
- HEAD-запросы не учитываются. Переходы не кешируются. Не сохраняются IP-адреса и cookie посетителей. Это счётчики обращений по ссылкам, не уникальные пользователи; боты и повторные клики могут их увеличивать.
- Счётчики хранятся отдельно от контента в `module_metrics`, обновляются атомарно и видны по каждому модулю и суммарно в панели.

## Docker и хранение

Миграция `005_admin_panel.sql` создаёт пользователей, статистику и поля оригинальной ссылки, публикации и времени обновления. Роль приложения получает только необходимые дополнительные права.

Фотографии из панели хранятся в named volume `module_uploads`, монтируемом в PHP как `/app/var/storage` и в nginx только для чтения. Они сохраняются при пересборке/redeploy. Публичный путь — `/media/modules/`. Коммитить их в Git или пересобирать Next.js для загрузки нового фото не требуется.

Резервное копирование БД включает пользователей и статистику. Volume с фото нужно резервировать отдельно вместе с БД. Не выполнять `down -v` или удаление volumes. Обычные PHP-сессии завершаются при замене backend-контейнера — после deploy администратор входит повторно.

Для ручной корректировки категории выбираются из текущего каталога. Начальная категория Compliance & Legal уже создана миграцией; дополнительные категории можно добавить существующим JSON-импортом/SQL. Веб-редактор категорий и управление услугами в эту панель не входят.
