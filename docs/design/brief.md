# Каталог и страница расширения

Пользователь выбрал две готовые визуальные ссылки 2026-10-16; новые варианты дизайна не требуются.

- `catalog-reference.png`: белая карточка, обложка 16:9 сверху, партнёр/категория/заголовок, описание, теги, цена, две кнопки и сравнение внизу.
- `extension-reference.png`: две равные колонки; слева главное изображение и миниатюры, справа партнёр, заголовок, рейтинг, описание, теги, блок partner price и установка.
- Согласованное изменение: отдельная ссылка README на карточке и в подробностях.
- Контент пользователь наполняет самостоятельно. Первым добавляется только Amasty CCPA с зависимыми партнёром, категорией и услугой установки. Supabase-экспорт не требуется.
- Используются существующие Inter, Lucide, CSS-токены, Next.js, Symfony и Docker. Новый frontend starter не создаётся: требуется production-проект на выбранном стеке.
- Официальные изображения CCPA используются как продуктовые материалы; исходные лого/иллюстрации других товаров со скриншотов не подменяются выдуманными изображениями.
- Главная карточки берёт `cover_image`, внутренние скриншоты — `gallery`; галерея на странице деталей объединяет их без дубликатов.

Источники контента: https://amasty.com/california-consumer-privacy-act-for-magento-2.html и https://amasty.com/user-guides/magento-2-california-consumer-privacy-act/ . Цена $159, рейтинг 4.5 / 2 отзыва проверены на странице Amasty 2026-10-16; данные можно изменить при наполнении. Цена нашей установки $60 взята из существующей записи CCPA в прежней SQL-миграции, не из карточки Product Feed на референсе.
