# SEO

SEO формируется сервером Next.js из опубликованных данных Symfony API. Деплой использует `SITE_URL`; в локальном Compose это `http://localhost:8085`. Изменения контента и импорта появляются в метатегах и sitemap без пересборки frontend.

## Метаданные и индексация

У модулей отдельно хранятся `seo_title` и `seo_description`, а также исходные метатеги вендора (`seo_source_title`, `seo_source_description`). Импорт и Upload заполняют их автоматически. Название и описание карточки не заменяются SEO-текстом.

Генератор использует метатеги источника, название и доступные возможности модуля. Из перегруженного title выбирается релевантная основная часть и максимум одно полезное уточнение без повторов. Редакционный предел title — 65 символов. Description собирается законченными предложениями до 160 символов; при слишком длинном исходном тексте используются название и реальные возможности модуля. Это обработка текста по правилам, без внешнего AI API и без выдуманных характеристик. Хороший исходный description может сохраняться без изменений.

Миграция `006_module_seo.sql` добавляет поля. Для старых модулей доступна команда, работающая только с сохранёнными данными, без скачивания страниц и изображений:

```bash
docker compose exec backend php bin/console app:seo:refresh
```

По умолчанию заполняются только пустые поля. `--force` явно перегенерирует заполненные поля. Production deploy после миграций автоматически заполняет недостающие SEO-поля. Исходные метатеги старых модулей появятся после следующего Upload; до этого используются уже сохранённые описания и возможности.

В админке в необязательной ручной корректировке есть отдельный раздел SEO. Upload снова генерирует эти поля из источника, как и остальное импортируемое содержимое.

- У публичных страниц собственные title, description, canonical, Open Graph и Twitter metadata. Description очищается от HTML и сокращается до 160 символов.
- Для категорий и вендоров без описания используется описание с их названием. При импорте описание категории также заполняется в БД, если оно пустое; авторский текст не перезаписывается.
- Карточки модулей используют обложку, статьи — своё изображение. Общая картинка `/social-image` генерируется с существующим логотипом в размере 1200×630.
- Пустые категории, вендоры, SEO-лендинги и пустые списки каталога/услуг/блога получают `noindex, follow`.
- Checkout и compare имеют `noindex, follow`. Админка, API, email и переходы `/go` — `noindex` в HTTP-заголовках; вход в админку также содержит meta robots.
- robots.txt разрешает обход, чтобы поисковый робот мог прочитать `noindex`. Административные страницы защищены авторизацией независимо от robots.txt.
- Несуществующие записи возвращают HTTP 404. Опубликованные страницы открыты для индексации. Это не подтверждает фактическое попадание в поисковый индекс.

## JSON-LD

Разметка включена в серверный HTML:

- Organization и WebSite со стабильными `@id`;
- Product для модулей, с реальным вендором как продавцом и его ценой/адресом предложения;
- Service для услуг; цена по запросу не размечается как бесплатная;
- BlogPosting для статей, включая реальные даты публикации и изменения;
- BreadcrumbList и CollectionPage / ItemList для страниц каталога.

Импортированные рейтинги вендоров не выдаются за собственные отзывы pubsetup.com и не включаются в aggregateRating. Наличие товара, сроки действия цены и другие отсутствующие сведения не выдумываются. JSON сериализуется с экранированием HTML-символов для защиты от вставки `</script>` из импортированного контента.

## Sitemap

`/sitemap.xml` генерируется из опубликованного каталога. Пустые разделы и служебные страницы исключены. `lastmod` берётся из `updated_at` / `created_at` / даты статьи; у разделов учитываются даты входящих материалов. Для статических юридических страниц неизвестная дата не подменяется текущим временем. URL удаляются из дублей.

## Проверки без браузера

```bash
npm --prefix frontend run test:seo
npm --prefix frontend run typecheck
npm --prefix frontend run lint
composer --working-dir=backend qa
# Только локальный запущенный Docker-стек:
docker compose exec -T backend php tests/seo-http.php
```

HTTP-проверка читает только локальный gateway: проверяет метатеги, JSON-LD, sitemap, lastmod, пустые категории, noindex, PNG для соцсетей и HTTP 404. Публичный сайт не проверяется.
